"# WingItBird" 
🛠️ What’s Under the Hood
HTML sets up the structure of the game—mostly a canvas and a score display.

CSS handles the look of the game: background colors, bird design, and some basic animations.

JavaScript does the heavy lifting: game logic, movement, collision detection, pipe generation, and keeping score.

✨ How It Works
The bird is controlled by pressing the spacebar which makes it "flap" and move upward.

Pipes scroll across the screen, and you have to guide the bird through the gaps.

You get a point every time you make it through a pair of pipes.

If you hit a pipe or fall to the ground, it’s game over—and time to try again.
